# 🚗 Uniride

Este projeto foi desenvolvido para a disciplina de **Experiência Criativa** do curso de **Engenharia de Software** na **PUCPR**. 

## Objetivo da Disciplina
O foco principal do projeto foi adquirir experiência prática na construção completa de uma aplicação real. O processo envolveu a documentação passo a passo de cada etapa do desenvolvimento e a definição de **Sprints** estruturadas de acordo com o alinhamento e necessidades do cliente.

## Sobre o Uniride
O **Uniride** é um site de caronas criado exclusivamente para estudantes, com o objetivo de facilitar a mobilidade até o campus, reduzir custos de transporte e incentivar a colaboração entre os alunos.

## Tecnologias Utilizadas
* **HTML5** & **CSS3** (Estruturação e estilização da interface)
* **JavaScript** (Interatividade no frontend)
* **PHP** (Lógica do sistema e comunicação com o banco de dados)
